# Supplier filament reference colors

Kromacut uses these sRGB references in the **Supplier Palettes** menu. The physical color of a
printed part can differ with the spool, print settings, and lighting. For optical blending, use a
calibrated Auto-paint profile with your spool's hiding distance. The added reference palettes
contain color names, RGB values, and source and product links.

## Sources

All links were checked on 2026-11-19. The five added sets come from the following pinned, MIT-licensed
sources. The display names match the manufacturers’ listed shade names. The manufacturer links
help identify the product line and may show different RGB values from the pinned color data.
Kromacut normalizes hex casing and assigns stable IDs scoped to the product line. Keep the IDs
when correcting names, links, or values.

| Supplier palette | Manufacturer | Color data source | Type |
| --- | --- | --- | --- |
| Polymaker Panchroma Basic PLA | [Official listing](https://shop.polymaker.com/products/panchroma-pla) | [Open Filament Database](https://github.com/OpenFilamentCollective/open-filament-database/tree/1c19d5088fbc19a434c426aae2006f7a3a4348d9/data/panchroma/PLA/basic_pla) | Community catalog, 28 colors |
| Prusament PLA | [Official listing](https://prusament.com/materials/pla/) | [Open Filament Database](https://github.com/OpenFilamentCollective/open-filament-database/tree/1c19d5088fbc19a434c426aae2006f7a3a4348d9/data/prusament/PLA/pla) | Community catalog, 20 selected colors |
| Prusament PETG | [Official listing](https://prusament.com/materials/prusament-petg/) | [Open Filament Database](https://github.com/OpenFilamentCollective/open-filament-database/tree/1c19d5088fbc19a434c426aae2006f7a3a4348d9/data/prusament/PETG/petg) | Community catalog, 13 selected colors |
| SUNLU PLA Classic | [Official listing](https://www.sunlu.com/products/pla-classic-filament) | [Open Filament Database](https://github.com/OpenFilamentCollective/open-filament-database/tree/1c19d5088fbc19a434c426aae2006f7a3a4348d9/data/sunlu/PLA/pla_classic) | Community catalog, 15 colors |
| ELEGOO PLA (RFID) | [Official listing](https://www.elegoo.com/products/pla-filament-1-75mm-colored-1kg) | [Ganja Panda's ELEGOO PLA library](https://github.com/Ganja-Panda/Elegoo-Centauri-Carbon-Series/blob/0290cfda6817c00e55c5f93b6de7d53dea42883f/README.md#-hueforge--elegoo-pla-filament-data) | Community transcription of color codes from ELEGOO RFID tags, 15 colors |

The SUNLU set takes its values from the PLA Classic product line in the pinned catalog. The
Prusament sets contain selected solid colors. The ELEGOO set uses the color codes reported by
the library author. The library's separate transmission-distance measurements are excluded.

The existing Bambu Lab PLA Basic palette transcribes the names and hex values from
[Bambu Lab's manufacturer chart](https://store.bblcdn.com/s7/default/1084369ef84345bbaa5d704a492954e0/Bambu_PLA_Basic_Hex_Code.pdf).
The chart does not state a redistribution license. The existing transcription is retained with
attribution, with no chart artwork included.
