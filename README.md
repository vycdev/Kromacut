## Features

- **Image editing.** Make non-destructive adjustments, crop and resize, reduce colors, and remove dithering. Retouch artwork with painting, text, and palette tools.
- **Auto-paint.** Plan a filament stack from the colors you own. Hiding Distance measurements help predict how thin layers blend.
- **Manual layers.** Choose the palette, arrange the print order, and set the height of each color.
- **Calibration and profiles.** Measure your filaments, compare printed color samples, and save or share reusable profiles.
- **3D preview.** Inspect each layer, compare simulated and physical colors, and explore shaded, transparent, or wireframe views.
- **STL and 3MF export.** Export STL or color-aware 3MF models, with filament swap instructions for layered prints.
- **Flat Paint.** Create uniform-thickness bookmarks, coasters, and other flat pieces, with 3MF export for multi-material printing.

| --- | --- |
| Windows | `*-setup.exe` |

## Development

Built with React, TypeScript, Vite, and Three.js. Desktop builds use Tauri.

Use **Node.js 22.18+** and npm:

```bash
npm ci
npm run dev
```

Run the checks and create a production build:

```bash
npm run lint
npm run test:docs
npm test
npm run build
```

<details>
<summary>Desktop development</summary>

Install Rust and the [Tauri platform prerequisites](https://tauri.app/start/prerequisites/), then run:

```bash
npm run tauri:dev
npm run tauri:build
```

Build artifacts are written to `src-tauri/target/release/bundle/`. See [TAURI.md](docs/TAURI.md) for build, packaging, and release details.

</details>
