# クイックスタート

このガイドでは、画像の読み込みから書き出しまで、一般的なプロジェクトの流れを説明します。

## 画像を読み込む・取り込む

プレビューツールバーのアップロードボタンを使うか、2Dプレビューに画像をドラッグします。

読み込み後は、マウスホイールでズームし、プレビューをドラッグして移動します。透明部分がある画像では、市松模様ボタンを使うと透明な領域が見やすくなります。

## 画像を調整する

**2D**では減色の前に**調整**を使います。露出、コントラスト、ハイライト、シャドウ、白レベル、黒レベル、彩度、自然な彩度、色相、色温度、色かぶり補正、明瞭度はすべて、パレットツールが検出する色に影響します。

減色、3D形状の作成、ダウンロードの前に、調整パネルの**適用**をクリックし、現在の調整を画像に反映してください。ライブ調整だけではプレビューにとどまり、元画像は更新されません。前後の例とリセット動作については[画像調整](image-adjustments)を参照してください。

## 必要に応じてサイズを変更する

印刷したい細かさに対して画像が大きすぎる場合は、減色前に**画像のサイズ変更**で割合を指定して縮小します。実際のピクセル寸法が小さくなるため、その後の3Dモデルをより速く作成でき、物理サイズも合わせやすくなります。

## 減色する

**減色設定**では次のようにします。

1. 特定のパレットを使う予定がなければ、**パレット**は**自動**のままにします。
2. **色数**は**16**から始めます。元の色領域を減らすには小さくし、細部が足りない場合は増やします。自動ペイントでは、この数はスプール数や交換回数ではありません。
3. **アルゴリズム**は既定の**K平均法**のままにします。多くの画像で最初に試すことを推奨する方法です。
4. **適用**をクリックします。

**画像の色**パネルで結果を確認します。色見本をクリックして編集したり、パレットから削除したりできます。削除はピクセルを残りの色に再割り当てします。輪郭からピクセルを除くには、消しゴムを使うかアルファをゼロ（完全透明）にします。

## ディザ除去・クリーンアップ

減色後に孤立した点が残る場合は、ノイズ除去として**ディザ除去**を使います。2D画像の孤立ピクセルは3Dモデルでも個別の形状になり得るため、特に役立ちます。

まず既定の**重み**と**回数**で**適用**をクリックします。1回の処理後も孤立ピクセルが多すぎる場合だけ回数を増やしてください。

## 3Dモードを有効にする

**3D**をクリックします。まず印刷の基本設定を行います。

- **ピクセルサイズ（XY）**は画像1ピクセルの物理的な幅と奥行きを決めます。
- **層の高さ**は使用予定のスライサーの層の高さと一致させます。
- **初層の高さ**はスライサーの初層設定と一致させます。
- **滑らかなメッシュ**はつながった色の境界を滑らかにし、形状を整えます。

## 手動か自動ペイントを選ぶ

減色後の画像の色を直接制御したい場合は**手動**を使います。手動モードは**画像の色**の色見本を使います。色をドラッグして印刷順を決め、各行のスライダーでその色が追加する厚みを指定します。層の順番がすでに決まっている場合や、小さく単純なパレットに合わせる場合に適した最初の選択です。

物理的なフィラメント積層をKromacutに計画させたい場合は**自動ペイント**を使います。自動ペイントは減色した画像の色見本ではなく実際のフィラメントから始め、それぞれの色と、下を隠す深さである**遮蔽距離（HD）**を使って積層の見え方を推定します。

最初の自動ペイントでは次のようにします。

1. 実際に印刷に使うフィラメントを追加します。
2. 各フィラメントの色をできるだけ正確に設定します。
3. 各フィラメントの**HD**を設定します。試すだけなら魔法の杖による推定で十分で、従来のTD値（HDの約10倍）から変換することもできます。通常は校正済みの遮蔽距離が最良の結果をもたらします。
4. 最初は**最大高さ**を**自動**のままにします。
5. 最初の結果で重要な色が欠ける場合や、より良いフィラメント順を探索したい場合は**高度な色合わせ**を有効にします。

自動ペイントが積層を計算したら、書き出す前に遷移領域と信頼度の詳細を確認します。信頼度が低い場合は、役立つ色のフィラメントが不足している、遮蔽距離の校正が必要、または最大高さが厳しすぎることが多いです。

## 生成して書き出す

**3Dモデルを作成**をクリックします。モデルが表示されたら、**層プレビュー**スライダーで下から上への積層を確認します。

ダウンロードメニューを開き、**STLをダウンロード**または**3MFをダウンロード**を選びます。その後、開始色、交換層、推奨スライサー設定がわかるよう、**印刷手順**をコピーします。
