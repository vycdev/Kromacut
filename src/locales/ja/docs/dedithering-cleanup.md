# ディザ除去とクリーンアップ

**ディザ除去**は、近くに同色の支持がないピクセルを周囲の色に置き換えます。独立した画像クリーンアップ処理であり、減色アルゴリズムでも、ノズルが印刷できる形状のシミュレーションでもありません。

同じ色が繰り返すディザ模様や、孤立した点のある減色画像に使います。元画像にそのような模様があれば減色前にも使えますし、減色後の領域にも使えます。写真用のノイズ低減フィルターではありません。写真では隣接ピクセルも厳密には少しずつ異なる色であることが多いためです。

## ピクセルの選択方法

![周囲8ピクセルが完全一致の色で投票します。重みは中央を残すために必要な同色近傍数を決め、繰り返し処理は直前の結果を使います。](36_dedither_neighbors.svg)

各ピクセルは斜めを含む直近の8近傍を調べます。**RGBとアルファが完全一致**する近傍が十分あれば、そのまま残ります。足りなければ、異なる近傍色のうち最も多いものに置き換わります。同数の場合はランダムに選ぶため、設定が同じでも毎回同じ結果になるとは限りません。

透明ピクセルを含め、すでに存在する近傍色だけを使います。平均して新しい色を作ることはありません。

## 重み

**重み**は元のピクセルを残すために必要な同色近傍数です。範囲は**1〜9**、既定値は**4**です。

| 例 | 結果 |
| ------------------------------------ | ------------------------------------------------------------ |
| 同色の近傍がない | 別の近傍色があれば、重み1でも変わります。 |
| 同色の近傍が3つ | 重み3では残り、重み4では置換対象になります。 |
| 中央と8近傍すべてが同色 | 別の近傍色がないため、重み9でも残ります。 |

低い値では細部が残りやすく、高い値では置換対象のピクセルが増えます。近傍は8つしかないので、重み9では保持の閾値に達しません。これは強い境界処理であり、半径を広げる設定ではありません。画像端のピクセルでは近傍数がさらに少なくなります。

## 回数

**回数**はクリーンアップを**1〜10**回繰り返し、既定値は**1**です。各回は直前の完成した結果を読み取ります。回数を増やすとしつこい点を除去できますが、輪郭を動かしたり、細い接続を切ったり、小さな文字を消したりすることもあります。

各項目のリセット矢印は重み4または回数1に戻します。パネルのリセットは両方を戻します。どちらも以前の画像は復元しません。画像を戻すには「元に戻す」を使います。

## 適用して確認する

1. 先に有効な画像調整を**適用**します。ディザ除去は調整後の表示を読み取るため、先に画像に反映すると処理済み結果にライブ調整が重なるのを防げます。
2. 1回から始めます。重みの既定値は4です。細い形状が重要なら低い値を試します。
3. **適用**をクリックし、大きくズームして輪郭、文字、透明な境界を確認します。
4. 同じ開始画像で別の設定と比較する前に元に戻します。

「適用」を繰り返しクリックすると、処理済み画像をさらに処理します。元画像に対する独立した比較にはなりません。

## 印刷への影響

孤立した異色ピクセルを除くと小さな色の島を消せますが、必要な細部も失う場合があります。アルファも投票に含まれるため、ディザ除去は輪郭を広げたり縮めたり、穴を開けたり閉じたりできます。

処理単位はmmではなく**画像のピクセル**です。0.1 mm/pxで3ピクセルの形状は、その後のメッシュやスライサーの処理前には0.3 mm幅です。ディザ除去にはノズル径の入力がありません。[3Dの印刷可能な細部の操作](3d-mode)とスライサーのプレビューで物理的な形状を確認してください。

## ディザ除去と高さディザの違い

| ツール | 場所 | 変わるもの |
| ---------------- | ---------------- | -------------------------------------------------------------------------------- |
| ディザ除去 | 2D | 完全一致の色領域と、場合によっては元画像の透明な輪郭。 |
| 高さディザ | 3Dの自動ペイント | 目標色に近づけるために生成される表面高さの模様。 |

片方を使っても、もう片方は有効になりません。意図的なピクセルアートや点描を保持する場合は、ディザ除去を適用しないでください。
