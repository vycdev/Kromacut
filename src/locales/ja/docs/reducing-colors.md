# 減色

減色は多数の元の色を少数に置き換え、手動と自動ペイントの3D方式で使う領域を単純化します。2Dパレットは目標となる画像の色であり、自動ペイントのフィラメントプロファイルや、実測による印刷予測ではありません。

先に切り抜きとサイズ変更を行います。[画像調整](image-adjustments)を変更した場合は、減色前にそのパネルの「適用」をクリックしてください。

## 2段階の処理

![アルゴリズムの重みは中間パレットを制限し、色数または選択した固定パレットが第2段階を制御します。](34_quantization_pipeline.svg)

**アルゴリズムの重み**と**色数**は役割が異なります。重み128のK平均法はまず元画像を最大128色にまとめます。色数16の自動設定は、その結果を最大16色に統合します。重みはパーセント、不透明度、フィラメント数ではありません。

| 項目または操作 | 意味 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| パレット：自動 | 画像に応じた色を見つけ、その数を制限します。 |
| パレット：内蔵、メーカー、独自 | 中間画像を選択したパレットの有効な色に割り当てます。利用可能な全色が使われるとは限りません。 |
| 色数 | 自動設定の最終上限。2〜256、既定16です。固定パレットでは無効です。 |
| アルゴリズムの重み | 中間パレットの許容量。2〜256、既定128です。高い値は通常、中間の細部を多く残しますが、最終的な一致が良くなるとは限りません。 |
| アルゴリズム | 第1段階の減色方法。既定はK平均法です。 |
| 適用 | 元の作業画像を処理し、元に戻す段階を作ります。設定を変えただけでは色は変わりません。 |
| リセット矢印 | 自動、16色、重み128、K平均法に戻します。以前の画像は復元しません。 |

出力色数は指定より少ない場合があります。減色後に目標数を増やしても捨てた色は戻りません。同じ元画像で別案を比較するには先に**元に戻す**を使ってください。

減色は完全透明ピクセルを保持しますが、**すべての半透明ピクセルを完全に不透明にします**。柔らかなアルファ境界は、部分的に印刷される境界ではありません。

## アルゴリズムを選ぶ

これらは色をまとめる方法です。どれも空間的なディザ模様を追加せず、小さな形状がノズルの線幅で残ることも保証しません。

| アルゴリズム | 変わるもの | 比較する場面 |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| なし（後処理のみ） | 第1段階の減色を省き、重みは無効になります。最終色数の削減または固定パレットへの割り当ては実行します。 | くっきりした絵柄を既知のパレットに直接割り当てます。「画像を一切変えない」万能の切り替えではありません。 |
| ポスタライズ | RGB各チャンネルを離散的な段階に分け、その後で重みの上限を適用します。 | 意図的に段階化したグラフィック向け。チャンネルの段階数は離散的に変わります。 |
| メディアンカット | 色分布を分割し、各区画を平均色で表します。 | 別の方法で重要な色調群が失われる場合に比較します。 |
| K平均法 | ランダムな初期値からピクセル数を重みにして色の集まりを探します。 | 写真や混合した絵柄の出発点。同じ元画像でも実行ごとに少し変わる場合があります。 |
| Wu | 色分布の統計から、区画内のばらつきが小さくなる分割を選びます。 | グラデーションや写真で比較します。 |
| オクトリー | RGBの細分化で色をまとめ、許容量に収まるよう集まりを統合します。 | はっきり分かれた領域が多い絵柄で比較します。 |

すべてに最良のアルゴリズムはありません。意図した物理サイズで主題、小さな文字、重要なアクセントを確認してください。

## 固定パレットとメーカーのパレット

固定パレットは選ばれた色だけを提供します。第1段階の減色後、透明でない各ピクセルはLab色空間で最も近い利用可能色に割り当てられます。これは画像の色合わせであり、フィラメントの光学シミュレーションではありません。

**メーカーのパレット**は、フィラメント名と公表された16進数色の非公式な参考セットです。現在の製品の入手可能性や印刷色の正確さは保証しません。たとえばBambuの参考色には[Bambu Labのフィラメント16進数色表](https://store.bblcdn.com/s7/default/1084369ef84345bbaa5d704a492954e0/Bambu_PLA_Basic_Hex_Code.pdf)を使います。Kromacutはメーカーと提携しておらず、公認でもありません。

内蔵パレットとメーカーのパレットは読み取り専用です。カスタマイズするには複製します。実物のスプールと層の挙動には、別途[フィラメント校正](calibration-theory)を使ってください。

## 独自パレット

| 操作 | 方法 |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 新しいパレットを作成 | 名前を付け、有効で正しい色を1つ以上追加します。作成後に選択されます。 |
| 選択したパレットを編集 | 現在の画像ピクセルではなく独自パレットを変更します。その後で減色を適用します。 |
| 色を追加 | カラーピッカー、16進数欄、任意の名前を追加します。有効な形式は`#RGB`または`#RRGGBB`です。不正な行は保存時に除外されます。 |
| 任意の色名 | スプール名などのラベルを付けます。色合わせには影響しません。 |
| 目の切り替え | 保存した色を削除せずに無効化します。有効で正しい色を1つ以上残す必要があります。 |
| 行を削除 | 行を削除します。最後の行は削除できません。 |
| 複製 | 自動以外のパレットを編集可能な独自パレットにコピーし、名前と無効化状態を保ちます。 |
| 読み込み | `.kpal`を読み、取り込み、上書き、重複、改名の結果を報告します。該当する場合は最初に取り込んだパレットを選択します。 |
| 書き出し | 選択した独自パレットを名前と無効色を含む`.kpal`として保存します。内蔵の編集可能コピーを書き出すには先に複製します。 |
| 選択したパレットを削除 | 保存したパレットを除き、選択を自動に戻します。画像ピクセルは消しません。 |
| 保存 / キャンセル | 編集中の下書きを確定または破棄します。 |

**自分のスプール（5/8）**のようなラベルは、保存した8色のうち5色が有効という意味です。有効な色だけが処理に使われます。パレットと選択はローカル保存されます。アプリやブラウザーの保存領域を消去する前にバックアップを書き出してください。[フィラメントプロファイル](settings-and-controls#filament-profile-files)とは別です。

## 画像の色

画像の色は、未適用のライブ調整ではなく元の画像を表します。バッジは完全透明ピクセルを除外します。ツールチップには16進数、アルファ、ピクセル数が表示されます。同じRGBでもアルファが違うと別項目になる場合があります。色数が非常に多い画像では、写真の全色ではなく上限付きのリストを表示します。

色見本をクリックして**色を編集**を開きます。RGBAピッカーまたは16進数欄を使い、適用します。6桁の16進数はピッカーの現在のアルファを保ってRGBを変え、8桁はアルファも明示します。不透明度が重要な場合は透明度操作または明示的なアルファ末尾を使います。

![不透明な置換は完全一致する全箇所を変色し、アルファゼロはそのピクセルを除去します。削除は穴を作らず色を再割り当てします。](35_swatch_operations.svg)

| 操作 | 変わるもの |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 不透明な色を適用 | 離れた領域を含め、画像全体のRGBとアルファが完全一致するすべてのピクセルを置き換えます。 |
| 完全透明のアルファを適用 | 完全一致するピクセルを可視画像と印刷輪郭から除きます。主題の一致ピクセルも消えます。 |
| 透明な色見本に適用 | 完全透明ピクセルをすべて置き換え、背景の追加や穴埋めになる場合があります。 |
| 削除 | 残った目標パレットで再減色します。ピクセルを**消去しません**。第1段階の選択アルゴリズムも実行されるため、他の色も変わる場合があります。 |
| 閉じる / Escape | 未確定の編集を破棄します。 |

残りのパレットへ直接割り当てるには、削除前に**なし（後処理のみ）**を選びます。局所的な変更には[塗りつぶしまたは消しゴム](loading-images#touch-up-pixels)を使います。意図した以上に変わったら元に戻してください。

透明でない色が64色を超えると手動交換手順は無効になります。それ以下でも小さなパレットは積層を単純化できますが、目標色が少なければ自動ペイントのフィラメント交換も少なくなるとは限りません。
