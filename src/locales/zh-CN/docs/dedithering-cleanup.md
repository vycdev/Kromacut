# 去抖动与清理

**去抖动**将局部缺少同色支持的像素替换为邻近颜色。它是独立的图像清理步骤，不是量化算法，也不模拟喷嘴的打印能力。

适合用于重复颜色的抖动图案，或有孤立杂点的减色图像。如果源图已包含这类图案，可在量化前使用，也可在量化后用于减色区域。它不是照片降噪滤镜，因为相邻照片像素的精确颜色通常略有不同。

## 如何选择像素

![周围八个像素按精确颜色投票。权重决定保留中心所需的同色邻居数；重复处理使用上一遍结果。](36_dedither_neighbors.svg)

每个像素检查包含对角线的八个直接邻居。如果足够多的邻居与其**RGB及Alpha完全一致**，便保持不变。否则采用出现最多的不同邻近颜色。并列时随机选择，因此相同设置不一定每次产生相同结果。

仅使用已有的邻近颜色，包括透明像素，不会平均生成新色调。

## 权重

**权重**是保留原像素所需的同色邻居数。范围为**1至9**，默认**4**。

| 示例 | 结果 |
| ------------------------------------ | ------------------------------------------------------------ |
| 没有同色邻居 | 只要存在另一种邻近颜色，即使权重为1也会改变。 |
| 三个同色邻居 | 权重3时保留；权重4时可被替换。 |
| 中心及八个邻居均相同 | 因没有不同邻色，即使权重9也会保留。 |

较低值通常保留细节；较高值让更多像素可被替换。只有八个邻居，因此权重9无法满足保留阈值。这是激进的边界设置，不是更大的半径。边界像素可用邻居也更少。

## 遍数

**遍数**重复清理**1至10**次，默认**1**。每遍读取上一遍的完整结果。额外遍数可移除顽固杂点，但也可能移动边缘、破坏窄连接或移除小字。

各字段的重置箭头将权重恢复为4或遍数恢复为1。面板重置同时恢复两者。这些操作都不会恢复先前图像；请用撤销恢复图像。

## 应用并检查

1. 先**应用**所有活动调整。去抖动读取调整后的视图，先写入图像可避免清理结果上仍叠加实时调整。
2. 从一遍开始。权重默认为4；细小特征重要时尝试较低值。
3. 点击**应用**，然后高倍率检查轮廓、文字及透明边缘。
4. 在同一初始图像上比较其他设置前，请撤销。

反复点击应用会继续清理已经清理过的图像，而不是与原图进行独立比较。

## 对打印的影响

移除孤立异色像素可消除小颜色孤岛，但也可能移除需要的细节。Alpha参与投票，因此去抖动可扩张或收缩轮廓，打开或关闭孔洞。

它按**图像像素**工作，而非毫米。在0.1 mm/像素下，三像素细节在后续网格或切片决策前宽0.3 mm。去抖动没有喷嘴直径输入。请使用[3D可打印细节控制](3d-mode)及切片预览检查实体特征。

## 去抖动与高度抖动

| 工具 | 位置 | 改变内容 |
| ---------------- | ---------------- | -------------------------------------------------------------------------------- |
| 去抖动 | 2D | 精确颜色区域，以及可能改变的源图透明轮廓。 |
| 高度抖动 | 3D中的自动配色 | 为逼近目标色而生成的表面高度图案。 |

使用其中一种不会启用另一种。保留有意设计的像素画或点描时，不要应用去抖动。
