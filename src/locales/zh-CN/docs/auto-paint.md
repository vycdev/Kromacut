# 自动配色控制

自动配色预测薄耗材层相互叠加的效果，为准备好的图像选择可打印高度。同一种实体耗材的不同厚度可产生多种可见颜色，因此二十种图像颜色不一定需要二十卷耗材。

设置[实体尺寸、层高及有效线宽](3d-mode#3d-print-settings)，添加实际可装载的耗材，等待计算，再**构建3D模型**。输入改变会自动重新计算；显示几何体仅在构建时更新。

## 耗材输入

| 控制 | 输入或操作 | 效果 |
| ---------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| **添加耗材** | 创建中性灰新行。 | 添加可用材料，不是实体打印机槽位。 |
| **色样 / 十六进制** | 选择耗材的不透明颜色或输入十六进制值。 | 改变混色及导出材料颜色。请输入实际耗材卷颜色，不是希望得到的输出色。 |
| **名称** | 为耗材卷提供有用标签。 | 用于识别。空名称恢复为基于颜色的自动标签。 |
| **HD** | 正面照明遮盖距离，0.01至2 mm。 | 较短HD更快遮住下层色。较长HD需要更大厚度，同厚度下透出更多。 |
| **从TD转换** | 输入传统光刻浮雕/背光透射距离，按**转换**。 | 约按TD × 0.1转换，舍入至0.01 mm并限制在HD范围。不要再次转换HD值。 |
| **魔棒** | 根据颜色估计HD。 | 起始猜测，不是测量。 |
| **状态标记** | 查看**估计**或校准置信度标签；悬停看RGB通道值。 | 描述本行HD证据，不代表整幅图像准确度。 |
| **垃圾桶** | 移除该行。 | 该耗材不再可用。保存前已存配置不变。 |
| **校准** | 打开遮盖距离、配色校样或叠层校准矩阵。 | 通过[校准流程](calibration-workflows)记录实体证据。 |

提交HD值、转换TD或使用魔棒会清除该行保存的HD校准。更改已校准耗材颜色会使校准失效，并使用颜色推导估计。恢复测量时颜色可重新启用保留的校准，除非期间已清除或替换。改名不是测量。

测得的通道行为同时影响预测颜色和过渡厚度。材料或工艺改变后，不要假设旧预览仍经验证。

## 耗材配置

加载已保存配置会替换工作耗材组合。**未保存更改**表示当前组合不同于选中配置。

| 操作 | 结果 |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| **保存更改到当前配置** | 以当前组合覆盖可编辑配置。无更改、未选配置或选中模板时禁用。 |
| **另存为新配置** | 输入非空名称单独保存，包括修改后的模板。 |
| **重命名选中配置** | 改变标签，不改变耗材。模板或未选配置时不可用。 |
| **从文件导入配置** | 读取原生`.kfil`、旧`.kapp`、JSON或支持的HueForge耗材卷CSV/TSV。 |
| **将当前耗材导出为.kfil文件** | 导出当前组合。桌面打开另存为；浏览器使用下载流程。取消不改变校准。 |
| **删除选中配置** | 移除已保存配置。需要时先导出备份。模板不能删除。 |

外观证据属于精确的耗材设置。选中配置有未保存编辑时，其保存的外观证据不会传入自动配色。导出这些编辑会创建单独命名的配置，不带旧组合不兼容的外观证据。活动的逐耗材HD校准与配置级矩阵和校样证据相互独立。参阅[配置兼容性与导入处理](settings-and-controls#filament-profile-files)。

### 模板

供应商模板提供宣传颜色、名称、品牌和估计HD，只读。移除未拥有的颜色，校准后**另存为新配置**。供应商参考颜色不保证具体批次或观察环境。模板是非官方的，不代表供应商认可。

## 标准匹配

**关闭增强颜色匹配**时，Kromacut按亮度将耗材从暗到亮排序并计算过渡，不遵循行添加顺序。图像到高度的映射也使用亮度：在最暗和最亮的非透明图像像素间归一化亮度，将该范围放在基础层表面和叠层顶部之间，再吸附至可打印层。因此，两个不同色相但亮度相同的颜色可能得到相同高度，与色相无关。重复、颜色分离、高度抖动及优化器控制不启用。

这种较简单基线适合以亮度为主的浮雕。增强匹配在选择材料顺序和可打印颜色分配时都考虑图像颜色，因此色相差异重要时应使用增强模式。

## 最大高度

清空**最大高度**或按**自动**，可使用计算得到、与层对齐的叠层高度。范围为0.5至20 mm。上限是天花板而非目标，因此结果可能更低。

处于有效层边界之间的上限向下取整。常规过渡过高时，Kromacut会压缩它们，并显示自动高度供比较。

![自动及高度受限叠层都保留不透明基础层，上方过渡则缩短。](15_transition_height.svg)

_示意图。彩带标识材料连续段，不代表预测混色外观。_

基础层仍必须在每个建模RGB通道达到约95%不透明度。上限不足会拒绝叠层，而非将透光衬底当成不透明。请提高上限，或使用HD更短、能充当基础层的耗材。

压缩可能移除有用中间色，它不是对相同图像进行均匀缩放。**平面打印模式**中，透明承载层是额外几何体，首层布局也不同于浮雕。请检查完整**模型**尺寸和切片厚度；最大高度不是含承载层的总板厚。

## 可打印细节

将[**3D打印设置**中的**有效线宽**](3d-mode#effective-line-width)设为切片软件的预期挤出宽度，而非喷嘴直径或像素尺寸。自动配色宽度警告预览和可选孤立色点清理使用同一设置，控制项仍在这里。

设想蓝色背景上的**两像素紫色条纹**。在**0.10 mm/像素**下，条纹**宽0.20 mm**。计划挤出线若**宽0.40 mm**，条纹就比线窄。Kromacut可将其标为**有风险**，但即使开启清理也保留条纹。细窄可见区域可能属于下方更宽的材料层；切片路径可能保留此仅基于图像检查所标记的细节。

![两像素紫色条纹窄于计划挤出宽度。琥珀色是宽度警告，不是耗材颜色。孤立色点清理保留条纹，仅将微小封闭粉点替换为蓝色。](13_printable_detail.svg)

_这是宽度估计，不是确切切片路径。色条比较宽度，方形图展示示例图像。_

**略去孤立色点**提供两种选择：

- **关闭：**自动配色输入保留全部源像素，包括每个高亮区域。
- **开启：**匹配及模型生成前，仅将专用于微小、紧凑、封闭色点的颜色替换为周围更宽的颜色。色点整体尺寸必须小于有效线宽，并有唯一明确且区域更宽的周围颜色。若该源颜色还用于图像任意位置的线条或更大区域，则各处均保留。

细线、对角连接、附着于较宽区域的分支、图像边缘细节，以及透明或多色旁的色点都会保留。清理绝不将像素变成孔洞，也不编辑原始2D图像。它有意保持谨慎，可能留下不需要的杂点；更广泛编辑请用[2D清理](dedithering-cleanup)。

使用**打开预览**检查：

- **有风险：**琥珀色标记靠近更宽颜色的细源色区域；粉色标记没有更宽邻居的细区域。其他像素变暗。这些是警告，不是细节无法打印的预测。
- **结果：**可选清理后自动配色收到的像素。它不是切片预览，也不保证可打印。
- **标记 / 符合条件 / 略去：**宽度警告比例、满足孤立色点规则的像素及实际替换数量。**保留的标记像素**明确统计不改变图像的警告。

符合条件的色点颜色被略去时，自动配色使用清理图像统计目标色并规划叠层。移除整个目标色可能改变其他位置的匹配，因此请检查重新构建结果。警告百分比非零但**略去0像素**，表示清理保留了全部源细节。

改变开关后，请等自动配色计算完成，再次点击**构建3D模型**。分析测量的是连通源颜色区域，不是实体材料层、墙、填充或可变宽度挤出。务必检查切片路径。如果细节确实在那里丢失，请增大模型XY尺寸、在2D中加宽，或选择打印机和切片软件支持的更细挤出宽度。

## 增强颜色匹配

增强匹配为当前2D调色板搜索材料顺序，可省略没有增加有效覆盖的耗材。八卷可用耗材不一定产生八个连续段。

优化器不会暗中再次减少准备好的调色板。源颜色越多，工作量越大。先按[减少颜色](reducing-colors)准备图像，再在3D中判断可实现外观。

关闭增强匹配也会关闭颜色分离和高度抖动。新计算取消旧计算；进度为近似值。失败计算不能回退到无关手动叠层。在构建有效新结果前，旧的已构建模型可能仍可见。

### 总重复限制

为整个叠层选择**关闭**，或最多**2、4、6、8、12次额外出现**。这既不是每种耗材的额度，也不是确切换料数。黑 → 黄 → 黑使用黑色的一次额外出现。在新衬底上再次使用材料，会创建另一条混色路径。

![共享重复额度及独立目标分配，与丢弃颜色后的合并对比。](14_repeats_separation.svg)

_概念顺序及分配，并非材料预测。_

更多重复允许更广搜索，也可能增加打印时的材料切换。额度是上限，不需要的连续段可省略。

### 保留颜色分离

普通匹配可能将不同图像颜色映射到同一输出。当区别重要，例如文字与背景或相邻面部色调时，启用**保留颜色分离**。

**唯一匹配限制（ΔE）**是某图像颜色拥有独立可打印输出所允许的严格最大色差。范围1至100，默认6。较低值要求更近的匹配，更难满足。较高值允许更多误差，不会改善实体耗材。

**要求每种颜色都有唯一匹配**默认启用，不完整分配会失败。关闭可使用**部分调色板**：未匹配颜色失去独立输出，合并到保留映射中。图像仍填满，但失去区别。若没有任何颜色符合条件，即使部分模式也失败，因为没有合并目标。

优化器先最大化保留颜色及源图覆盖，再优先减少重复出现、材料连续段和实体层，最后降低限制内误差。重复额度逐步探索，所有颜色保留后可停止搜索。最后的删除检查移除不能改善这些优先目标的单独连续段。

严格失败时，可考虑减少2D颜色、增加高度或重复、添加合适耗材、提高ΔE限制或接受部分合并。请选择实际想要的取舍，不要仅为消除错误而提高限制。

颜色分离和**高度抖动**互斥。启用任意一项会关闭另一项。

## 高度抖动

输入含有可用层边界之间的高度时，高度抖动可将舍入误差分布到相邻可打印高度的小块中。从一定距离观察，这些高度差可能呈现中间色调。它需要增强匹配，作用于导出的高度图，而非2D源图。

![有小数高度时的高度抖动机制：比较直接吸附与将舍入误差分散到附近可打印高度。](16_height_dithering.svg)

_机制示意，不保证前后结果。不同顶面高度不代表增加耗材卷颜色。_

当前许多自动配色映射在此步骤之前已经选择离散可打印层。已吸附区域没有小数高度误差可分散，启用抖动后可能不变。请用重新构建预览和切片软件检查当前图像是否确实获得高度变化；开启开关不保证更多色调或可见点。

点尺寸由**3D打印设置**的**有效线宽**相对于**像素尺寸**决定，并舍入到整像素块尺寸。这是近似值，不是确切最小宽度保证。边缘区域避开相同抖动处理以减少边界伪影。请在切片软件中检查小孤岛及额外移动。

存在小数高度误差时，重新分布可帮助大面积色调，但可能使微小图形有噪声或几何更重。它不能补充缺失色域，也不能验证不支持的校准。产生许多小区域时，与平面打印结合尤其昂贵，因为这些区域共处于每个完整占地层中。

## 优化器设置

![同一图像的均匀、中心与边缘优先，以及更高过渡细节带来的更多潜在高度选择。](18_optimizer_choices.svg)

_权重和选择为示意，不是测量颜色或确切层数。暗化区域优先级较低，并未从图像移除。_

| 控制 | 选项与效果 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **算法** | **快速：**较窄、较快的搜索。**平衡：**通用默认值。**彻底：**更深的多起点改进。**深入：**更广、更昂贵的搜索。**精确基础顺序：**枚举适用的无重复顺序。 |
| **区域优先级** | **均匀：**像素等权。**中心加权：**偏重中央附近颜色。**边缘加权：**偏重图像边缘颜色。改变匹配优先级，不改变裁剪或挤出。 |
| **过渡细节** | **紧凑（80%）**、**详细（90%，默认）**、**最大（95%）**设置过渡不透明度终点。较高值允许更高过渡及更多可打印中间色，但受提前收敛和高度上限限制。 |
| **种子（可选）** | **自动**使用由输入导出的稳定种子。输入整数可比较另一确定性搜索；清空恢复自动。它不是质量滑块。 |

过渡细节影响上方材料过渡，不改变不透明基础层要求。它不提高图像分辨率，也不缩窄线宽。额外过渡色可能对当前图像无用。

相同种子下，更高启发式级别保留下一级的最佳结果，但仍只是优化预测。精确基础顺序在八种耗材时检查109,600个非空顺序，九种时986,409个。重复使用独立改进流程，不穷尽证明所有重复叠层。

## 过渡区域与置信度

| 读数 | 解释 |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **过渡区域** | 带起点、终点及厚度的实体材料连续段。压缩标记表示厚度低于理想值。 |
| **总高度 / 实体层数** | 计算得到的叠层尺寸，不是图像颜色或耗材卷数量。 |
| **颜色分离状态** | 保留和合并颜色、可打印容量、保留色最差ΔE及重复。合并目标不是成功的超限匹配。 |
| **外观模型** | 预测由模拟、拟合行为、局部比较还是矩阵证据支持。测量计数不代表每个输出都经测量。 |
| **预测置信度：平均 / 最低** | 实际映射颜色的证据强度。加权平均可能隐藏最低值揭示的薄弱区域。计数区分测量、插值、拟合预测及模拟。 |
| **结果置信度** | 综合HD校准、覆盖及压缩指标。不是测得准确度百分比，也不同于预测置信度。 |
| **校准 / 覆盖 / 压缩** | HD证据质量、耗材对源颜色的覆盖及高度上限影响。高分不认证打印。 |
| **质量分数** | 优化器比较，不是测量。非严格颜色分离不完整时，标签变为**部分调色板**。 |
| **迭代 / 缓存命中** | 搜索工作量及结果复用。更多迭代不证明颜色更好。 |
| **精确最优 / 已找到最佳** | 适用无重复顺序的穷举比较，与启发式或重复叠层改进的区别。均不证明实体准确度。 |
| **无可移除连续段** | 删除任一连续段均无法保持所选优先目标。另一多段重排可能仍更好。 |

远离测量、附近观察互相矛盾，或留出预测未命中测量色时，证据减弱。普通匹配可包含有限的不确定性成本。颜色分离仍以原始ΔE判断资格，因此不确定性不能让超限颜色变有效。

改变工艺或层高后，请检查此证据摘要。较高总体校准分不代表每个新配方都受支持。参阅[校准流程](calibration-workflows)。

## 建议下一种耗材

存在结果后会出现**建议下一种耗材**。它寻找可改善当前图像覆盖的假设颜色，不是产品目录，也不是已装入打印机的耗材卷。

| 字段或操作 | 含义 |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **十六进制色样** | 建议的不透明耗材颜色。 |
| **预计ΔE +…%** | 添加后考虑混色的平均图像误差预计下降幅度。越高越好，不是置信度。 |
| **HD** | 按感知色距从最近现有耗材借用的起始估计，不是某产品的测量。 |
| **覆盖改善** | 估计误差改善的图像像素百分比。 |
| **独立性** | 与当前耗材的区别，范围0至1。较高表示更独立的覆盖缺口。 |
| **添加到耗材** | 添加名为`Kromacut-Suggestion-…`的工作行并重新计算。 |

建议有用时，请寻找实际耗材卷并输入真实颜色及校准。不要假设该假设行已经可用就打印。图像颜色或耗材组合改变时建议重置。无候选表示在此近似测试下，当前组合已较好覆盖图像。
