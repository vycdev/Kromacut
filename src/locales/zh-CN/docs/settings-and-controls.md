# 设置与控制

本页汇总影响整个应用或容易忽略的控制项。

## 顶部控制

| 控制 | 作用 |
| ------------- | ------------------------------------------------------------------------------ |
| Kromacut标志 | 文档打开时返回应用，否则打开主页。 |
| 设置 | 打开设置对话框，包括语言、主题、资源及更新控制。 |

主题选择器提供**系统**、**深色**及**浅色**。**系统**遵循操作系统或浏览器的配色偏好，并随其变化更新。主题选择会保存供后续会话使用。

**语言**选择器改变界面、文档、图表及公开页面。选择**系统语言**可遵循支持的浏览器或操作系统语言，也可选择英语、法语、德语、意大利语、罗马尼亚语、西班牙语、日语、简体中文、印地语、欧洲葡萄牙语、乌克兰语或孟加拉语。选择保存在本地，不改变图案、耗材配置、打印设置或生成几何体。翻译资源和字体随桌面应用打包；在线翻译服务不会收到您的作品。

公开页面也有语言选择器。翻译文档使用可分享的语言前缀链接，例如`/ro/docs/overview`。页面名及章节锚点在不同语言间保持稳定。文件扩展名、模型数值数据、用户输入名称及社区作品原始标题不会翻译。

设置对话框包含文档、Discord、Reddit、GitHub及Patreon链接，并显示当前Kromacut版本。

## 工作区模式

使用**2D**和**3D**按钮在图像准备与模型生成间切换。

控制面板和预览之间的竖直分隔条可拖动。处理详细设置时加宽左面板，检查图像或模型时加宽预览。

文档页面使用可分享的`/docs/...`链接。打开链接会直接进入对应指南。

较小屏幕上，展开**目录**选择指南，或展开**本页内容**跳转到章节。选择后两者都会关闭，留出阅读空间。点击图示，或聚焦其链接后按Enter，可全尺寸打开。

多数侧栏章节可通过标题折叠。折叠只隐藏控制，不隐藏效果：活动调整、打印设置及优化器选项仍适用。折叠摘要和状态点可帮助发现活动变化。章节开闭状态会被记住，展开不会重置。

**撤销 / 重做**在2D与3D之间共享图像编辑历史，不是耗材编辑、校准、层高或优化器设置的撤销栈。可用时请使用各面板自身的重置控制，恢复图像状态后重新构建。

## 实验性多打印板模式

设置中的**多打印板模式**是未完成流程。它会记住偏好并可播放预览动画，但目前不拆分图像、不创建分块、不将对象分配到多块打印板，也不改变导出几何体。正常打印请关闭。不要用它将超大模型适配到热床。

## 已保存打印设置

Kromacut在浏览器中记住**像素尺寸（XY）**、**层高**、**首层高度**、**有效线宽**及**平滑网格**等打印设置。

若要恢复该区域默认值，包括0.42 mm有效线宽，请使用**3D打印设置**中的重置按钮。

记住的设置仅属于当前浏览器/站点或桌面应用，不是图案备份或完整已保存项目；不同浏览器或桌面应用不一定共享它们。清除应用/浏览器数据前，请导出重要调色板和耗材配置。加载配置恢复的是耗材与证据，不是图像或已构建网格。

## 已保存自动配色状态

自动配色设置会跨会话保留，包括：

- 耗材。
- 配色模式。
- 最大高度和校准楔块层高。
- 增强颜色匹配。
- 保留颜色分离、其唯一匹配ΔE限制，以及是否要求每种颜色唯一匹配。
- 总重复限制（整个叠层共享的额外耗材出现次数）。
- 过渡细节和高度抖动。
- 用于宽度警告、孤立色点清理及高度抖动的有效线宽（在**3D打印设置**中编辑），以及保存的**略去孤立色点**偏好。清理偏好不会移除所有宽度警告，也不控制高度抖动。
- 平面打印模式及其正面朝上、无透明层偏好。
- 优化器算法和种子。
- 区域优先级。

配置与此记忆状态分开。需要可加载、导入或导出的命名耗材组合时，请使用配置。

## 调色板文件

自定义调色板用于2D减色，文件使用`.kpal`。

调色板格式版本2添加两个可选字段：`disabledColors`（保留在调色板中但不参与量化的颜色）和`colorNames`（每种颜色的可选显示名称）。两者均可在导出和导入间完整保留。版本1文件原样加载，所有颜色启用且无名称；旧版Kromacut打开v2文件时会简单地将所有颜色视为启用。

希望减色图像匹配已知耗材组合或固定色集时，请使用自定义调色板。

## 耗材配置文件

自动配色耗材配置是可保存、加载、导入和导出的命名耗材组合。它们使用`.kfil`，保存耗材颜色、名称、遮盖距离、校准数据、已保存配色校样记录和评价，以及可用时的有限叠层校准矩阵计划及测量颜色。旧`.kapp`文件仍可导入。旧版本保存的未校准值使用传统TD尺度，加载或导入时自动转换（×0.1）。

使用自动配色配置工具栏中的**上传图标**导入文件。同ID的旧文件没有外观数据时，会作为单独重命名副本导入，避免抹掉较新校准证据；存储失败会保持现有配置列表不变并显示错误。用**下载图标**导出当前耗材组合。导出默认使用`.kfil`。已加载配置有未保存耗材编辑时，会导出为新的“未保存编辑”配置，不携带绑定旧耗材身份的外观证据。

### 支持的导入格式

| 格式 | 扩展名 | 说明 |
| ----------------------- | -------------- | ------------------------------------------------------------------------------ |
| Kromacut配置 | `.kfil` | 原生格式。支持一个文件中的单个配置及配置数组。 |
| 旧Kromacut配置 | `.kapp` | 旧原生格式，导入仍完全支持。 |
| 原始JSON | `.json` | 文件包含配置对象或配置对象数组时可接受。 |
| HueForge耗材卷CSV/TSV | `.csv`, `.tsv` | 见下文。 |

### 重复处理

导入时，Kromacut将每个传入配置与现有配置比较：

- **同ID：**通常覆盖已有配置。如果会用不含可用证据的文件替换已保存外观证据，则改为导入单独副本。
- **同内容、不同ID：**只有耗材数据及外观证据都匹配已有配置时才跳过。
- **同名称、不同内容：**导入时在名称后添加数字后缀，例如`My Spools (2)`。

每次导入后会简要汇总导入、覆盖、跳过或重命名的配置数量。

### 从HueForge导入

HueForge耗材卷库导出（`.csv`或`.tsv`）可直接导入。在HueForge中使用**Export Spools**保存CSV，再点击自动配色耗材配置工具栏的上传图标并选择文件。分隔符（逗号或制表符）从标题行自动检测。每卷耗材成为名为`<Brand>-<Color Name>-<Hex>`的条目，例如`Inland Basic-Light Brown-#BF9C81`。HueForge UUID保留为耗材ID，因此再次导入相同库不会创建重复项。HueForge TD值视为传统背光/光刻浮雕TD输入，导入时转换为正面照明遮盖距离。

## 桌面更新通知

桌面应用中，新版本可用时Kromacut可显示更新通知。通知允许打开下载页面或关闭提醒。

打开**设置**可手动检查更新。桌面设置也包括**启动时检查**，控制应用打开时是否检查更新。默认启用；关闭后仍可手动检查。

在 Linux 上，嵌入了更新信息的 AppImage 可以通过 AppImageUpdate 等兼容工具更新。这些工具使用发行版的 `.AppImage.zsync` 文件下载发生变化的部分。没有更新信息的旧版 AppImage 需要先手动下载一次支持此功能的版本。`.zsync` 文件不是安装程序，Kromacut 的更新通知也不会自动安装更新。

## 桌面自动配色诊断

桌面应用可记录新自动配色计算的结构化信息。开始计算前，打开**设置**并启用**记录自动配色诊断**。此设置不会重新启动或补录已经计算的结果。

每次计算在Kromacut自动配色诊断文件夹中创建独立`.jsonl`文件。使用设置旁的**打开文件夹**查找。每行都是完整JSON事件，因此即使计算未完成，进度、错误和取消信息仍可读取。

完整记录包含基本运行时信息、活动耗材及校准快照、构建与优化器设置、有限进度采样、外观拟合状态、逐步重复级别决策、最终实体层、所有最终可打印颜色候选、目标到候选的Delta E比较、预测置信度，以及对插值或局部拟合颜色有贡献的测量。记录的是处理后的调色板颜色和权重，不是上传的源图。校准和配置数据仍可能敏感，因此公开分享前请检查记录。

记录用于调查，可能生成大文件。普通打印不需要记录时，请保持禁用。

## 从桌面打开文件

桌面安装将 `.kfil` 和旧版 `.kapp` 文件关联到耗材配置，将 `.kpal` 文件关联到调色板。双击文件即可在 Kromacut 中导入并选中它。如果应用已经运行，会使用现有窗口处理文件。仍然遵循通常的验证、迁移、重复处理和校准保留规则。

调色板编辑器、校准对话框或配置的重命名、新建保存表单打开时，从桌面打开的文件会等待处理。完成或取消当前操作后，排队的导入将继续；在此之前，已输入的名称和正在编辑的配置保持不变。

编辑耗材名称或HD字段时，或者该耗材的颜色选择器或**从TD转换**弹出面板打开时，导入也会等待。移开输入框焦点或关闭选择器、弹出面板后，排队的导入会继续；在其他配置替换未保存的耗材修改前，仍会要求你作出选择。

替换未保存的耗材修改之前，Kromacut 会提供 **保留修改** 或 **打开配置**。选择保留修改后可先保存；打开配置则会放弃这些修改。以此方式打开的文件必须小于 32 MiB。普通 JSON、图片和模型仍使用通常的导入流程。

在 Linux 上，便携式 AppImage 需要桌面集成才能关联文件。如果系统没有将 Kromacut 设为默认应用，请在文件管理器中使用 **打开方式**。
