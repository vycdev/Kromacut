# 多打印头打印

多打印头模式会重新组织 [Auto-paint](auto-paint) 选定的可打印堆叠。同一层的不同图像区域可以使用不同耗材。多个打印头在手动重新装料之间保持耗材可用；分析会寻找预测颜色匹配更好的方案，并安排必要的重新装料。暂停次数可能减少，但并无保证。

## 前提条件

- 使用 **Auto-paint**，在列表中至少添加一种耗材，然后启用**多打印头模式**。
- 选择 **2–8 个打印头**和**搜索深度**，然后点击**生成 3D 模型**。分析至少需要两种可用耗材才能形成有用的窗口。

多打印头模式与 **Flat Paint** 互斥。请校准实际拥有的耗材，参见[校准理论](calibration-theory)。模式、打印头数量和搜索深度会在会话之间保存。更改输入后请重新生成模型。

## 色段与窗口

**色段**是 Auto-paint 堆叠中使用同一种耗材的连续层块。其厚度来自 Auto-paint 的可打印结果，包括校准和高度限制，而不只是原图亮度。

**窗口**包含 N 个连续色段。N 受所选打印头数量和可用耗材数量限制。分析会选择有用且互不重叠的窗口，并不会自动将所有色段分组。所选窗口之外的色段保留原定耗材，也会纳入打印头计划。

![色段被分成示例窗口，其余色段保留原定耗材。](01_window_run_diagram.svg)

## 为每个窗口选择耗材

窗口内有 K 种不同耗材和 N 个色段位置时，包括重复在内共有 **K^N** 种顺序。分析使用 **ΔE** 色差比较预测混色，为每个图像颜色区域分配顺序。色段位置并非固定的物理打印头，计划会将所需耗材映射到打印头。

![改变相同耗材的顺序会改变预测混色；颜色仅为示意。](03_beer_lambert_blending.svg)

![三种耗材和三个位置的 27 种顺序，以及展示 K^N 增长的表格。](05_combo_search_space.svg)

**搜索深度**控制窗口选择门槛、可选择的窗口数量以及测试的顺序数量：

- **快速**使用较少的窗口选择迭代和较小的组合预算。
- **均衡**是默认设置，兼顾计算量和搜索覆盖范围。
- **全面**允许更多窗口和更大的组合预算，但较大的搜索空间仍可能采用采样。

在每种深度的预算内会测试所有组合。更大的空间使用数量受限且结果可复现的样本，并包含当前顺序。相同输入会产生可重复的结果。所有深度考虑的图像颜色相同；更深入的搜索并不保证实物打印效果更好。 有关目标色的分组方式，请参阅[颜色分组](#color-grouping)。

## 颜色分组

开始搜索前，Kromacut 会将调色板中的颜色分成要尝试再现的目标色。**颜色分组**控件决定分组方式：

- **按层分组（当前）** — 在 Auto-paint 结果中映射到同一打印层的颜色会合并成一个目标。因此，不同色相可能共用一个目标。每个有颜色的层最多有一个目标组。
- **按颜色分组（色相）** — 不同色相可以在各自原来的打印层上保留为独立目标。大型调色板会按组数预算缩减，但每个有颜色的层至少保留一组；不同打印层的颜色绝不会合并。

按颜色分组不保证降低颜色误差或增加打印出的颜色数量。结果取决于图像、耗材校准、打印头数量和所选窗口。搜索会最小化 CIE76 色差；搜索得分更低时，CIEDE2000 误差仍可能更高。构建也可能耗时更长。可打印的颜色仍受耗材及其实际堆叠方式限制。

颜色分组设置一经更改就会保存，无需先构建。请分别使用两种选项重新构建，并比较图像预览。

## 打印头计划与导出

成功生成后，预览会显示每个区域按分配耗材得到的模拟颜色。**物理颜色**则显示实际耗材颜色。打开**打印说明**并遵循**打印头计划**：

- 打印前，将列出的每种耗材装入对应编号的打印头。标为**空**的打印头保持不使用。
- 在每个列出的层检查点，仅为标记的打印头重新装料。未变化的装料状态会保留，并非每个窗口边界都需要暂停。
- 导出 **3MF** 可保留已分配的几何形状、物理耗材颜色和打印头分配。文件将所选打印头数量记为挤出机数量，并在计划中的换料检查点添加 **M600** 暂停标记。STL 不保留这些分配。

![三个打印头在各阶段之间保留未变化的耗材，只有装料变化的打印头需要手动重新装料。](02_nozzle_swap_schedule.svg)

请使用兼容的多打印头打印机。打印前，在切片软件中检查打印头映射、首层及常规层高和暂停处理方式。一个检查点可能需要为多个打印头重新装料。

## 回退与重新生成

如果分析失败，或找不到能改善普通堆叠的可用布局，将生成普通单打印头模型，并显示提示及原有起始颜色和换色说明。尝试其他耗材、打印头数量或搜索深度后，重新生成模型。

分析在后台运行。离开 3D 面板或更改图像会取消进行中的分析；请为新图像重新生成模型。说明和导出描述的是已生成模型，因此更改设置后需重新生成以应用修改。
