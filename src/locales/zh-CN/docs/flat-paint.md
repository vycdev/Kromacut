# 平面打印模式

**平面打印模式**是可用于标准或增强匹配的自动配色布局。它生成厚度一致的平板，而非阶梯浮雕。每个打印层都覆盖模型占地范围，同一层中可能有不同材料并排分布。

请使用AMS、CFS或换刀器等多材料流程，并搭配适用的切片支持。只在某个高度手动换料，无法在该层并排提供多种材料。

如果构建失败，Kromacut 会移除未完成的模型，并在预览中显示错误。点击“构建 3D 模型”重试；构建成功后，模型尺寸和图层预览会重新显示。

## 默认：透明承载层、正面朝下

启用**平面打印模式**，让**正面朝上，无透明层**保持关闭。

1. 透明承载层首先打印，贴着打印板形成平滑观察面。将其对象分配给透明耗材。
2. 图案各列反转通常的材料顺序，供从下方观察。基础材料填充较矮列的背后。
3. 导出**3MF**并保持方向。图案已做镜像，不要在切片软件中再次镜像。
4. 打印后翻转部件，透过承载层观察。

在切片软件中从背面看时，文字可能反向。请检查预定的观察面。将Kromacut预览旋转到下方可检查该面。

承载层是额外几何体，需要实际透明耗材。屏幕透明效果不能衡量耗材透明度或打印板表面效果。请在**模型**标记和切片软件中检查总厚度，不要只看自动配色的**最大高度**。

## 正面朝上，无透明层

启用此开关可移除透明承载层：

- 每列保持通常从下到上的材料顺序。
- 基础材料填充较矮列下方，使可见颜色对齐在平整顶面。
- 没有承载层对象，也不需要透明耗材。
- 按导出方向正面朝上打印，不做镜像，直接观察裸露顶面，无需翻转。

这些布局具有不同几何体。改变开关后，请再次**构建3D模型**。翻转旧导出文件不会将其转换为另一布局。

## 比较工作流程

| 流程 | 观察面 | 几何体 | 切片分配 |
| ------------------- | ---------------------------- | --------------------------------------------------- | ---------------------------------- |
| 普通自动配色 | 阶梯顶面 | 较矮列提前停止。 | 按高度排列的实体材料连续段。 |
| 平面打印，默认 | 透过透明承载层的底面 | 镜像、反转材料顺序的列，基础层在后方。 | 每种耗材的对象加承载层。 |
| 平面打印，正面朝上 | 裸露平整顶面 | 通常顺序，基础层位于较矮列下方。 | 每种耗材的对象，无承载层。 |

**平滑网格**可用于平面打印的两种朝向。选择强度后重新构建。平滑处理会柔化外轮廓和颜色间的共享边界，同时保持平板表面、层高和材料堆叠顺序。对角接触使用小型共享连接，使区域闭合而不重叠。打印说明和3MF会记录构建时的强度。

## 导出与检查

仅提供**3MF**。无色STL会丢失有意义的材料布局，只剩平板。对象按实际耗材分组，而非按每种预测混合色分组。

1. 将常规层高和首层高度与Kromacut一致。
2. 保持比例和导出方向，不要再做镜像。
3. 正确分配每个对象，包括默认承载层的透明耗材。
4. 检查各切片层中的并排区域及完整平板。
5. 从预定观察面确认文字方向，再检查换料及打印时间。

**打印说明**以特定布局的多材料指南替代手动换料列表。**层预览**使用普通轨道，因为每层可能包含多种材料。其截止范围仍只影响检查，绝不影响完整导出。

## 成本与细节取舍

平整表面不一定更容易打印。每层填满占地会比浮雕增加材料及几何体负担。薄层、高叠层及**高度抖动**可能产生许多小区域、更多移动，并减慢构建、导出或切片。

Kromacut会在构建大型平面打印任务前警告。**仍然构建**表示接受该工作量，不证明打印机适用。材料或表面效果未经验证时，请先测试小块。平面打印保留预期的光学列排列，但仍依赖校准材料和一致的打印工艺。
