# 减少颜色

量化用较少颜色替换大量源颜色，简化手动及自动配色3D流程使用的区域。2D调色板包含目标图像颜色，并非自动配色耗材配置或测量得到的打印预测。

先裁剪并调整尺寸。如果更改了[图像调整](image-adjustments)，请在量化前点击该面板的应用。

## 两阶段流程

![算法权重限制中间调色板；颜色数量或选定固定调色板控制第二阶段。](34_quantization_pipeline.svg)

**算法权重**与**颜色数量**承担不同任务。权重128的K均值先将源图分成最多128色。颜色数量16的自动模式再将结果合并至最多16色。权重不是百分比、不透明度，也不是耗材数量。

| 字段或操作 | 含义 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 调色板：自动 | 查找依赖图像的颜色，再限制数量。 |
| 调色板：内置、供应商或自定义 | 将中间图像映射到所选调色板的启用颜色。不是所有可用颜色都必须出现。 |
| 颜色数量 | 自动模式的最终上限：2至256，默认16。固定调色板时禁用。 |
| 算法权重 | 中间调色板额度：2至256，默认128。较大值通常保留更多中间细节，不一定带来更佳最终匹配。 |
| 算法 | 第一阶段减色方法。默认K均值。 |
| 应用 | 处理底层图像并创建撤销步骤。仅修改设置不会重新着色。 |
| 重置箭头 | 恢复自动、16色、权重128及K均值。不恢复先前图像。 |

输出可能少于请求的颜色数。减色后提高目标数无法恢复已丢弃颜色：先**撤销**，再从同一源图比较其他方案。

量化保留完全透明像素，但会使**所有半透明像素完全不透明**。柔和Alpha边缘不等于部分打印的边缘。

## 选择算法

这些方法对颜色分组。没有一种会添加空间抖动图案，也不保证小特征能在喷嘴线宽下保留。

| 算法 | 改变内容 | 适合比较的情况 |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 无（仅后处理） | 跳过第一阶段量化器，禁用权重。最终颜色数量减少或固定调色板映射仍运行。 | 将干净图案直接映射到已知调色板。它不是通用的“保持图像不变”开关。 |
| 色调分离 | 将RGB通道分成离散等级，然后执行权重限制。 | 有意设计的阶梯式图形；可用通道等级会离散跳变。 |
| 中位切分 | 将颜色分布分成若干桶，以平均色表示。 | 其他方法丢失重要色调组时比较。 |
| K均值 | 随机初始化，寻找按像素数量加权的颜色簇。 | 照片及混合图案的起点。同一源图多次运行可能略有不同。 |
| Wu | 使用颜色分布统计选择组内变化较小的分割。 | 在渐变和照片上比较。 |
| 八叉树 | 通过RGB细分对颜色分组，再合并组以符合额度。 | 在具有许多独立区域的图案上比较。 |

没有普遍最佳的算法。请在预期实体尺寸下检查主体、小字及重要点缀。

## 固定与供应商调色板

固定调色板只提供选定颜色。经过第一阶段减色后，每个非透明像素映射到Lab色彩空间中最近的可用颜色。这是图像色彩匹配，不是耗材光学模拟。

**供应商调色板**是耗材名称及宣传十六进制颜色的非官方参考集合，不保证当前产品供应情况或打印颜色准确度。例如，Bambu参考颜色使用[Bambu Lab耗材十六进制色表](https://store.bblcdn.com/s7/default/1084369ef84345bbaa5d704a492954e0/Bambu_PLA_Basic_Hex_Code.pdf)。Kromacut与制造商没有隶属关系，也未获其认可。

内置和供应商调色板只读。克隆后可自定义。实际耗材卷及叠层表现请单独使用[耗材校准](calibration-theory)。

## 自定义调色板

| 控制 | 操作 |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 创建新调色板 | 命名并添加至少一种已启用的有效颜色。创建后自动选中。 |
| 编辑选中调色板 | 更改自定义调色板，不更改当前图像像素。随后应用量化。 |
| 添加颜色 | 添加取色器、十六进制字段及可选名称。有效格式为`#RGB`或`#RRGGBB`；保存时省略无效行。 |
| 可选颜色名称 | 为颜色添加标签，例如耗材卷名。不改变匹配。 |
| 眼睛开关 | 禁用已保存颜色而不删除。必须保留至少一种有效颜色处于启用状态。 |
| 移除行 | 删除该行；不能删除最后一行。 |
| 克隆 | 将非自动调色板复制为可编辑自定义调色板，保留名称及禁用标记。 |
| 导入 | 读取`.kpal`文件并报告导入、覆盖、重复或重命名项目。适用时选择第一个导入调色板。 |
| 导出 | 将所选自定义调色板保存为`.kpal`，包括名称及禁用颜色。内置调色板需先克隆才能导出可编辑副本。 |
| 删除选中调色板 | 移除已保存调色板，并将选择恢复为自动。不擦除图像像素。 |
| 保存 / 取消 | 提交或丢弃编辑器草稿。 |

**我的耗材（5/8）**之类的标签表示保存了八项，其中五种颜色启用。只有启用颜色参与处理。调色板及选择保存在本地；清除应用/浏览器存储前请导出备份。它们与[耗材配置](settings-and-controls#filament-profile-files)相互独立。

## 图像颜色

图像颜色描述底层图像，而非未应用的实时调整。其标记不计完全透明像素。提示显示十六进制值、Alpha及像素数。不同Alpha值可能产生RGB相同的独立项目。颜色极多的图像显示有限列表，而非每一种照片颜色。

点击色样打开**编辑颜色**。使用RGBA取色器或十六进制字段，再应用。六位十六进制值改变RGB并保留取色器当前Alpha；八位值明确包含Alpha。重视不透明度时，请使用透明度控制或明确的Alpha后缀。

![不透明替换会重新着色所有精确匹配，Alpha零会移除这些像素，而删除会重映射颜色而非挖孔。](35_swatch_operations.svg)

| 操作 | 改变内容 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 应用不透明颜色 | 替换整幅图像中RGB与Alpha完全匹配的像素，包括不相连区域。 |
| 应用完全透明Alpha | 从可见图像和可打印轮廓移除精确匹配像素。主体中匹配的像素也会消失。 |
| 应用于透明色样 | 替换所有完全透明像素，可能增加背景或填充孔洞。 |
| 删除 | 使用剩余目标调色板重新量化。它**不会**擦除像素。所选第一阶段算法仍会运行，因此其他颜色也可能变化。 |
| 关闭 / Escape | 丢弃未提交编辑。 |

删除前选择**无（仅后处理）**可直接映射到剩余调色板。局部更改请用[填充或橡皮擦](loading-images#touch-up-pixels)。图像改变超出预期时请撤销。

非透明颜色超过64种时，手动换料说明禁用。即使低于该限制，较小调色板也可简化叠层，但更少目标色并不自动意味着更少自动配色换料次数。
