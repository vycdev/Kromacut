# 3D模式

3D模式将图像颜色转为实体层。在2D中准备图像，选择尺寸和打印方式，再点击**构建3D模型**。更改设置不会自动重新构建显示的模型。

使用**手动**自行选择颜色顺序和厚度。使用**自动配色**预测实际耗材混色，并为图像寻找叠层。两种方式都不操作打印机：请导出模型并在切片软件中检查。

## 3D打印设置

| 控制 | 对模型的影响 | 检查内容 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **像素尺寸（XY）** | 两个水平方向每图像像素对应的毫米数。 | **模型**标记在构建前估计实体宽度、高度和深度。 |
| **层高** | 高度与换料使用的常规垂直步长。 | 与切片软件一致。薄层提供更细的高度选择，而非更窄的挤出线。 |
| **首层高度** | 打印板上方的第一步高度。 | 单独匹配此值。首种颜色至少达到常规层高和首层高度中较大者。 |
| **有效线宽** | 用于自动配色可打印细节检查和高度抖动的挤出宽度。 | 与切片软件的预期线宽匹配，而非喷嘴直径或像素尺寸。它不改变打印机配置。 |
| **平滑网格** | 将像素阶梯边界变为平滑连续轮廓。 | 改变导出几何体，不只是光照。不会添加图像细节或熨平表面。 |
| **重置** | 恢复0.1 mm/像素、0.12 mm常规层、0.2 mm首层、0.42 mm有效线宽及关闭平滑。 | 同时将手动厚度重置为最小值，并保留当前颜色顺序。 |

### 像素尺寸不是喷嘴尺寸

宽1,000像素的图像在**0.1 mm/像素**下产生约**100 mm**宽的模型。在**0.2 mm/像素**下，使用完全相同图像像素，宽度变为约**200 mm**。透明外边距不计入模型边界。

![增大像素尺寸会让同一图像网格实体更大；调整图像尺寸则改变像素数量。](10_physical_size.svg)

_示意图。XY尺寸、图像分辨率和挤出宽度是独立控制项。_

若使用2,000图像像素仍保持100 mm宽，请设为**0.05 mm/像素**。更多像素可描述更细边缘，但打印机仍有挤出宽度限制。在**3D打印设置**中设置**有效线宽**，再用自动配色的[可打印细节预览](auto-paint#printable-detail)检查该限制。

增大像素尺寸不减少像素数，也不会天然降低网格生成成本。若要减轻构建，请在[2D模式](loading-images)中调整尺寸、裁剪或简化调色板。

### 有效线宽

将切片软件的预期挤出宽度复制到**有效线宽**。范围为0.1至2 mm。重置**3D打印设置**会将其与其他默认值一同恢复为0.42 mm。编辑此字段不改变打印机配置。

自动配色使用此宽度进行宽度警告预览、可选孤立色点清理及高度抖动块尺寸计算。检查警告或略去孤立色点的控制仍位于[自动配色](auto-paint#printable-detail)。警告不表示特征会被移除或无法打印。

### 层高与有效边界

采用**0.20 mm首层**及**0.08 mm常规层**时，层顶面位于0.20、0.28、0.36、0.44 mm，而不是0.08、0.16、0.24、0.32 mm。Kromacut将颜色厚度调整到此网格。

改变**层高**会将手动厚度重置为新常规步长，再应用首色最小值。改变**首层高度**会将首色重置为新最小值。请在调节滑块前设置这些值；之后若有更改，重新检查计划。

字段接受较宽的应用范围：像素尺寸0.01–10 mm/像素、层高0.01–10 mm、首层高度0–10 mm。这些是输入限制，不是推荐打印机设置；首色仍会调整到实体最小值。请使用喷嘴、材料和切片软件支持的值。更细高度改变自动配色的可用配方，不会自动使已有校准兼容。

## 手动模式

**颜色层段厚度**列出非透明的**图像颜色**。每行含拖动手柄、色样、厚度滑块及毫米读数。该值是颜色连续段的厚度，不是绝对顶面高度。一个连续段可跨越多个切片层。

![三个手动连续段形成累计高度；增厚下方连续段会抬高每个后续表面。](11_manual_layers.svg)

_截面示意。后续颜色表面下方包含前面的连续段。_

例如，常规层高0.08 mm时，将黑色设为**0.20 mm**、红色**0.16 mm**、白色**0.08 mm**。黑色区域停在0.20 mm，红色0.36 mm，白色0.44 mm。红色从切片第2层开始，白色从第4层开始。打印前请确认生成说明及切片软件的解释。

### 重新排列颜色

按打印顺序从上到下拖动各行。最上行从打印板开始。后续行只在图像需要的位置打印到前面行之上，形成阶梯浮雕。移动颜色会改变衬底材料、表面高度及换料顺序。移到首位的行会在需要时提高到首层最小值。

手动预览和导出使用图像颜色，不使用自动配色HD模型。即使手动预览显示红色，黑色上的薄红层也可能比色样更暗。请据此选择材料和厚度。

### 调整与重置厚度

拖动滑块并松开以提交。后续连续段按**层高**递增。首段从最小值开始，再增加常规步长。增厚下方连续段会抬高所有后续表面并移动换料位置，而不只影响下方颜色仍可见的区域。

**颜色层段厚度**重置按亮度从暗到亮排序，并分配最小厚度。它不同于**3D打印设置**重置，后者也改变实体打印参数，但保留顺序。

手动控制和换料说明支持**64色**。更大调色板请在2D减少颜色。完全透明像素表示无材料，而不是白色衬底。除非图像将其连接，否则不相连的不透明孤岛仍是独立部件。

## 平滑网格

关闭平滑时，轮廓遵循方形像素网格。开启时，将连续边界平滑为焊接几何体。差异会导出，不是预览滤镜。

平滑预览和导出模型的轮廓。中度保留原有的平滑效果。重新构建后应用。

| 强度 | 用途 |
| --- | --- |
| **无** | 像素画、精确的方格边缘或最快生成。 |
| **轻度** | 轻微平滑锯齿状角点。 |
| **中度** | 与原来启用平滑时的效果相同。 |
| **强度** | 进一步平滑轮廓和残留的阶梯状边缘，保持与中度相同的位移上限。 |

顶点位移保持在源像素的一半以内。重新构建模型并检查切片预览。旧的开启/关闭设置对应中度/无。

![在同一源网格上比较像素阶梯和平滑的斜向轮廓。](12_smooth_boundaries.svg)

_轮廓示意比较，不是切片模拟。_

曲线或斜线轮廓看起来过于阶梯化时使用。保留有意像素画或精确网格边缘时关闭。两者都无法修复小到不可打印的细节，也不会凭空增加源分辨率。

[平面打印模式](flat-paint)下平滑网格不启用。开启平滑网格会禁用平面打印；平面打印改用覆盖完整占地的平板构造。

## 自动配色

自动配色接受实际耗材颜色和**遮盖距离（HD）**，预测混色，并将图像颜色映射到可打印高度。全部耗材、匹配、细节及置信度控制请参阅[自动配色控制](auto-paint)。

## 校准耗材遮盖距离

耗材列表下方的**校准**打开**遮盖距离**、**配色校样**及**叠层校准矩阵**。打印与记录结果请参阅[校准流程](calibration-workflows)，光学模型请参阅[校准理论](calibration-theory)。

## 耗材配置

配置保存命名耗材组合及兼容证据。未保存编辑不会自动写回选中配置。参阅[耗材与配置](auto-paint#filament-profiles)及[配置文件](settings-and-controls#filament-profile-files)。

### 模板

模板是只读供应商参考集合，不是您手中耗材卷的测量。加载、调整、校准后，**另存为新配置**。参阅[模板](auto-paint#templates)。

## 最大高度

上限在有效层边界缩短自动配色过渡，但不能移除不透明基础层。请阅读[最大高度](auto-paint#max-height)，包括平面打印承载层的注意事项。

## 可打印细节

在**3D打印设置**中设置**有效线宽**，再在自动配色中用**打开预览**检查细窄源颜色区域。**略去孤立色点**可选地替换仅用于微小封闭色点的颜色，同时保留细线和相连细节。警告及实际略去像素数分开显示。参阅[可打印细节](auto-paint#printable-detail)。

## 增强颜色匹配

搜索带重复、独立颜色要求或空间高度抖动的材料顺序。这些选择在颜色覆盖、厚度、换料及计算量间取舍。参阅[增强颜色匹配](auto-paint#enhanced-color-matching)。

## 平面打印模式

制作多材料平板而非阶梯浮雕，可使用正面朝下的透明承载层，或无承载层正面朝上。观察方向和对象分配很重要，导出前请阅读[平面打印模式](flat-paint)。

## 优化器设置

**算法**、**区域优先级**、**过渡细节**及**种子**调整匹配，不调整打印机速度。参阅[优化器设置](auto-paint#optimizer-settings)。

## 过渡区域与置信度

区域描述实体连续段；置信度描述证据和模型限制，不是测得的打印准确度。参阅[解读结果](auto-paint#transition-zones-and-confidence)。

## 配色校样

将打印试样与选定图像颜色比较，记录哪些候选匹配。参阅[校准流程](calibration-workflows#palette-proof-compare-artwork-colors)。

## 叠层校准矩阵

拍摄已保存配方板，验证对齐，并保存兼容叠层的测量颜色。参阅[校准流程](calibration-workflows#stack-matrix-photograph-known-recipes)。

## 预览控制

用鼠标主键拖动旋转，滚轮缩放，副键拖动平移。相机移动不会改变实体尺寸。

| 工具栏控制 | 用途 | 对打印的影响 |
| ------------------ | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **准确颜色** | 不使用场景照明或电影色调映射，比较选中色样。 | 仅预览。仍取决于模型和显示器，不是校准验证。 |
| **着色** | 检查有照明的浮雕和形状。 | 仅预览；光照改变表观颜色。 |
| **透明** | 查看重叠层。 | 仅预览，不会使耗材透明。 |
| **线框** | 检查按层着色的特征边缘。 | 仅预览，不是挤出路径。 |
| **预览颜色** | 切换自动配色模拟混色与实体耗材颜色。 | 仅预览。导出保留实际材料分配。 |
| **相机切换** | 透视深度或无透视缩短的正交对齐。 | 仅预览，保留相机位置。 |
| **撤销 / 重做** | 遍历共享图像编辑历史。 | 不是3D字段或耗材编辑的撤销栈。图像改变后需重新构建。 |
| **下载** | 导出已构建STL或3MF。 | 使用上次构建模型，而非未应用的侧栏设置。 |

视图模式及模拟/实体选择会被记住。**预览颜色**只在已构建的自动配色模型中出现。

## 层预览

拖动底部条的下限及上限控制点可隔离一个高度范围。位置吸附到层网格。悬停材料段可查看起始或换料信息。

![截止控制点为检查隐藏层，但导出仍包含完整模型。](19_preview_only.svg)

_示意图。屏幕上隐藏层绝不会将其从导出删除。_

平面打印使用普通轨道，因为一个打印层可含多种材料。将默认正面朝下布局旋转到下方以查看图案。

自动配色计算失败可能留下之前成功的构建可见。不要将其视为新设置成功的证明。存在构建快照时，打印说明使用该快照。解决错误，重新构建，然后检查并导出。
