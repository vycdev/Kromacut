# 概述

Kromacut将平面图像变成颜色分层叠加的3D打印作品。核心思路很简单：图像中的颜色变为实体层，而这些层的顺序和高度成为打印计划。

如果您想制作HueForge风格的打印作品、彩色光刻浮雕风格的作品，或通过换料形成最终图像的分层展示品，可以使用Kromacut。

## 主要工作流程

多数项目遵循相同路径：

1. [加载或导入图像](loading-images)。
2. [减少颜色](reducing-colors)，直到预览具有可打印的调色板。
3. 如果图像有噪点，对孤立像素进行[去抖动或清理](dedithering-cleanup)。
4. 切换到[3D模式](3d-mode)，选择手动或自动配色。
5. [构建并导出](generating-exporting-output)STL或3MF文件，按打印说明操作。

## 两种配色方式

Kromacut在3D模式中提供两种打印流程。

| 流程 | 适用情况 | 可控制内容 |
| ---------- | ------------------------------------------------------ | --------------------------------------------------------------------------- |
| 手动 | 希望直接控制每一种图像颜色。 | 颜色顺序、每种颜色的层段厚度、打印设置和换料。 |
| 自动配色 | 希望由Kromacut规划实体耗材叠层。 | 耗材颜色、遮盖距离值、最大高度及优化器选项。 |

手动模式从**图像颜色**面板中的颜色开始。自动配色从实际耗材及其**遮盖距离（HD）**开始，为图像生成可打印层。

## 应用中的内容

使用2D准备图案，使用3D规划实体层。下方指南也按此区分组织。

## 图解指南

从想完成的任务开始。每份指南解释控制项、它们的相互影响以及对实体打印的后果。图表为示意例子，并非经过校准的颜色预测。点击图示或通过键盘激活，可按完整尺寸打开。

| 任务 | 指南 |
| ------------------------------------------------------------------ | -------------------------------------------------------------- |
| 设置尺寸、层高和手动颜色顺序 | [3D模式](3d-mode) |
| 选择耗材、优化混色并检查可打印细节 | [自动配色](auto-paint) |
| 制作正面朝上或朝下的平整多材料板 | [平面打印模式](flat-paint) |
| 测量HD、比较配色校样或拍摄叠层校准矩阵 | [校准流程](calibration-workflows) |
| 准备轮廓并修整像素 | [加载图像](loading-images) |
| 调整色调和颜色，然后应用结果 | [图像调整](image-adjustments) |
| 减少颜色并管理调色板 | [减少颜色](reducing-colors) |
| 清除杂点，同时区分2D清理与高度抖动 | [去抖动与清理](dedithering-cleanup) |
| 检查完成的叠层并传至切片软件 | [生成与导出](generating-exporting-output) |

## 工作区布局

工作区有三个主要区域：

- 顶部包含文档、主题控制和社区链接。
- 左侧面板包含当前模式的控制项。
    - **2D**中显示调整、去抖动、量化、自定义调色板及检测到的图像颜色。
    - **3D**中显示打印设置、手动控制、自动配色控制和打印说明。
- 主预览显示2D图像画布或3D模型。

> 提示：3D设置不会自动重新构建模型。更改打印设置、手动层段厚度或自动配色选项后，请点击**构建3D模型**。

## 适合首次尝试的项目

先选一张对比度高、主体清楚且背景细节有限的图像。将其减少到4至16色。若已知道所需层顺序，可使用手动模式；若已校准耗材遮盖距离，则使用自动配色。
